# 齿轮（GB/T 4459.2）

## 几何（标准直齿圆柱齿轮，压力角 20°，ha* = 1，c* = 0.25）

| 量 | 公式 |
|---|---|
| 分度圆 | d = m·z |
| 齿顶圆 | da = d + 2(1 + x)m |
| 齿根圆 | df = d − 2(1.25 − x)m |
| 全齿高 | h = 2.25m |
| 中心距（标准或高度变位） | a = m(z1 + z2)/2 |
| 顶隙 | c = 0.25m，等于 a − ra1 − rf2 |

**变位**：z < 17 时标准齿轮会根切，最小变位系数 x_min = (17 − z)/17（例如 z = 15：0.118，取 0.12）。
小齿轮正变位、大齿轮负变位且 x1 + x2 = 0（高度变位），中心距不变。变位后的齿顶线、齿根线位置要用上面的公式重新算。
变位系数写进技术特性表。图片上的齿根线位置往往不准，要用参数算，不要量。

模数用标准系列（第一系列）：1、1.25、1.5、2、2.5、3、4、5、6、8、10…

## 单个齿轮的画法

- 视图：齿顶线（圆）粗实线；分度线（圆）细点画线；齿根线（圆）细实线，也可以不画。
- 剖视（剖切平面通过轴线）：**轮齿按不剖处理**。剖面线只画到齿根线；齿根线用粗实线；齿顶线到齿根线之间的齿带留白，分度线画在留白带里。
- 齿顶两端倒角（约 0.5m×45°），倒角线是两条横线。

## 结构（课程设计常用比例）

- da ≤ 160 左右：实心式；d_a ≤ 500：腹板式（锻造或铸造）。
- 腹板式：轮毂外径 D1 ≈ 1.6·ds（ds 为孔径），轮毂长 L = (1.2~1.5)ds，且 ≥ b；腹板厚 C ≈ 0.3b；轮缘厚 δ0 = (2.5~4)m ≥ 8 mm。
- 轮毂上的键槽贯通全长。

## 齿轮轴

小齿轮齿根到键槽底的距离 e < 2.5m（圆柱齿轮）时，齿轮和轴做成一体（齿轮轴）。
画法：轴按不剖画；轮齿两端从**端面上的齿根圆**用 45° 倒角倒到齿顶。所以端面线只画到齿根圆，齿顶线比齿宽短 2×(ra − rf)。
要表达啮合时，在啮合一侧用局部剖：剖面线从齿根线（粗实线）往轴心画，波浪线为界，齿带仍留白。

## 啮合画法（两轴线所在平面剖切）

- 两齿轮的分度线重合，画细点画线。
- 啮合区里，一个齿轮（通常是主动的小齿轮）的轮齿画成可见：齿顶线粗实线；另一个齿轮的齿顶线被挡住，画**细虚线**（也可以不画）。
- 两齿轮的齿根线都画粗实线。
- 一个齿轮的齿顶线和另一个齿轮的齿根线之间留出 0.25m 的顶隙。
- 端视图（垂直于轴线）：两齿顶圆都画粗实线（啮合区内也可以省略），分度圆相切。

## 齿轮工作图上的参数表（右上角）

模数 m、齿数 z、压力角 α、变位系数 x、精度等级（如 8-7-7 GB/T 10095）、配对齿轮的齿数、中心距及偏差、公法线长度或齿厚及偏差。
