# 齿轮箱的设计顺序（一级圆柱齿轮减速器为例）

按顺序来，每一步只用前面已经定下的数。每个尺寸记下来源：设计输入 / 公式 / 标准表 / 经验值 / 按原图取。
以下经验值是课程设计常用的数，具体以设计手册为准。

## 1 传动比和齿轮

- 设计输入：功率 P、输入转速 n1、传动比 i（单级圆柱齿轮 i ≤ 5 左右）。
- 选 z1（软齿面 20~40，闭式小尺寸也常见 15~20；z1 < 17 要变位），z2 = i·z1 取整，核算实际传动比。
- 模数 m 由齿面接触强度和弯曲强度计算后取标准值；中心距 a = m(z1 + z2)/2。
- 齿宽：b2 = ψd·d1（ψd 约 0.8~1.2，取整），小齿轮 b1 = b2 + (5~10)。
- 变位、齿顶圆、齿根圆见 [gears.md](gears.md)。

## 2 轴

- 最小直径：d ≥ C·(P/n)^(1/3)，45 钢 C = 103~126；有一个键槽加大 5%~7%，取标准值。低速轴扭矩约为高速轴的 i 倍，直径约为 i^(1/3) 倍。
- 外伸端直径还要和联轴器、带轮的孔相配。
- 由外向里逐段定直径：
  - 非定位轴肩：+1~3 mm（方便装配）；
  - 定位轴肩：高度 h = (0.07~0.1)d；
  - 装轴承的轴段取轴承内径（5 的倍数）；轴承定位肩直径 ≥ 安装尺寸 da min，且小于内圈外径（便于拆卸）；
  - 装密封件的轴段取密封件的标准内径；
  - 装齿轮的轴段比轴承段大一些，便于从一端装入。
- 齿轮根圆到键槽底 e < 2.5m 时做成齿轮轴。
- 轴段长度由轴向布置决定（第 4 步），装齿轮的轴段比轮毂短 2~3 mm，保证套筒或轴肩压紧。

## 3 键和轴承

- 键按轴径查 GB/T 1096，见 [keys-threads-fasteners.md](keys-threads-fasteners.md)。
- 轴承：按轴承段直径选型（直齿轮常用深沟球轴承 62 系列），校核寿命；安装尺寸 da、Da 查手册。

## 4 箱体和轴向布置

- 铸铁箱体壁厚：δ = 0.025a + 1 ≥ 8 mm（一级圆柱齿轮减速器）。
- 大齿轮齿顶到箱体内壁 Δ1 ≥ 1.2δ；齿轮端面到箱体内壁 Δ2 ≥ δ。
- 轴承端面到箱体内壁 Δ3：脂润滑 8~12 mm（要装挡油环），油润滑 3~5 mm。
- 轴承座宽度 L ≈ δ + c1 + c2 + (5~8)，c1、c2 由连接螺栓规格查表。
- 箱体外形由轴承座、螺栓位置（离箱壁 c1、离边 c2）和底座决定。
- 端盖形式（嵌入式或凸缘式）决定轴承外端面的位置和游隙调整方式。

## 5 总装

1. 齿轮装上轴 + 键 → 齿轮轴部件。
2. 加上套筒、挡油环、轴承 → 轴系部件。
3. 轴系装进箱体的轴承座（按中心距 a 定位）。
4. 装调整环或垫片、端盖、密封件、紧固件。
5. 标注装配图尺寸、序号、明细栏、技术特性表、技术要求。

## 和原图对照

从一张图片重画时：先按上面的顺序推出尺寸，再和图上的标注对照。对不上的地方（原图常常不按比例，或者省略了参数）不要硬凑图形，列给用户看。

原图和规则冲突时谁说了算：
- **原图写明的**（标注的尺寸、配合代号、标准件型号、零件结构）：照原图画。不符合规则的地方列给用户，由用户决定改不改，不要自己悄悄改（例如原图端盖配合 K7/h10 偏紧，照画并指出）。
- **原图没写、要推算的**（变位系数、键长、齿根圆、未标注的倒角和间隙）：按规则和公式取，并注明来源。
- **原图看不清的**：按规则取，并告诉用户是推算的。

量出来的总长比标注短，先看原图是不是用了**断开画法**（轴上有波浪线或双折线）：断开的轴画短了，标注写的是实际长度。这时照原图断开画，尺寸文字写实际长度，不要把轴加长去凑。
