# 装配图（GB/T 4458.2 序号、GB/T 10609.2 明细栏）

## 装配图要有的内容

1. 一组视图：表达工作原理、装配关系和主要零件的结构（主视图常沿主要装配干线剖切）。
2. 必要的尺寸，见下文。
3. 技术要求（文字）：装配、调整、检验、润滑、密封、试车要求。
4. 零件序号、明细栏、标题栏。
5. 减速器还要有**技术特性表**：输入功率、输入转速、传动比、效率，以及各级齿轮的 m、z、x、b、精度等级。

## 必须标的尺寸（五类）

- **规格（性能）尺寸**：中心距 a 及偏差（如 70±0.023，按齿轮精度查）。
- **装配尺寸**：配合尺寸（Ø32H7/k6、轴承 Ø30k6 / Ø62K7）、重要的相对位置。
- **安装尺寸**：地脚螺栓孔的直径、孔距，轴伸出端的直径和长度。
- **外形尺寸**：总长、总宽、总高。
- **其他重要尺寸**：设计时算出、不能改的尺寸。

零件的全部尺寸不在装配图上标，那是零件图的事。

## 配合怎么写

- 一般配合写成分式：Ø32 H7/k6（孔/轴）。
- 与标准件（滚动轴承）的配合只写非标准件一侧的公差带：轴 Ø30k6、孔 Ø62K7。
- 常用：齿轮与轴 H7/r6 或 H7/k6；联轴器与轴 H7/k6；套筒与轴 E8/k6 或 D11/k6（松）；端盖与座孔 K7/h10、H7/f9；轴承内圈 k6、m6，外圈 H7、J7、K7。

## 零件序号

- 每种零件一个序号；相同零件只编一次，数量写进明细栏。
- 序号写在指引线末端的横线上或圆里，字比尺寸数字大一号或两号。
- 指引线从零件的**可见轮廓内**引出，起点画小圆点；零件太薄或涂黑时，起点改用箭头指到轮廓上。
- 指引线不能互相交叉；穿过剖面时，不能和剖面线平行；必要时可以折一次。
- 序号沿水平或垂直方向排列整齐，按顺时针或逆时针依次编号。
- 一组紧固件（螺栓、螺母、垫圈）可以用一条公共指引线。

## 明细栏

- 放在标题栏上方，自下而上填写；地方不够时可以接在标题栏左边。
- 栏目：序号、代号（图号或标准号）、名称、数量、材料、重量、备注。
- 标准件在“名称”里写规格，在“代号”里写标准号，例如：滚动轴承 6206，GB/T 276。

## 简化画法

- 零件上的小圆角、倒角、退刀槽可以不画。
- 相同的一组零件（螺栓组、轴承的滚动体）可以只详细画一个，其余用中心线表示位置。
- 滚动轴承可以一侧用规定画法、一侧用通用画法。
- 拆卸画法：沿结合面剖切，或拆去某些零件后画（在视图上方注明“拆去××”）。
