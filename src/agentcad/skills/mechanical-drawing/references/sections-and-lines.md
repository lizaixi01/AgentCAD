# 线型、剖视、剖面线（GB/T 4457.4、4457.5、17453、4458.6）

## 线型

| 线 | 画什么 | 线宽 |
|---|---|---|
| 粗实线 | 可见轮廓线；齿轮的齿顶线，剖视图中的齿根线；螺纹牙顶线；螺纹终止线 | d（常用 0.5 或 0.7） |
| 细实线 | 尺寸线、尺寸界线、剖面线、引线；螺纹牙底线；视图中的齿根线（也可以不画） | d/2 |
| 细点画线 | 轴线、对称中心线、分度线（圆） | d/2 |
| 细虚线 | 不可见轮廓线；啮合区里被挡住的齿顶线 | d/2 |
| 波浪线 | 局部剖视的边界、断裂边界 | d/2 |
| 双点画线 | 相邻辅助零件、运动件的极限位置 | d/2 |

装配图里不可见的轮廓线一般不画，除非不画就看不懂。

## 剖面线（金属材料）

- 用与主要轮廓或剖面对称线成 45° 的细实线（AgentCAD：ANSI31，pattern_angle 0 为 45°，90 为 135°）。
- **同一零件**在所有视图、所有剖视里剖面线方向和间距都相同。
- **相邻零件**剖面线方向相反，或方向相同但间距明显不同。三个零件相邻时，第三个用不同间距。
- 剖面宽度 ≤ 2 mm 的薄件（垫片）可以涂黑。
- 非金属（毡圈、橡胶、密封材料）用网格线（ANSI37）。

## 装配图中不剖的零件

剖切平面通过以下零件的轴线（纵向剖切）时，这些零件**按不剖**画，只画外形：
轴、杆、键、销、螺栓、螺柱、螺钉、螺母、垫圈、滚动体（滚珠、滚柱）、手柄、连杆。

要表达轴上的键槽、销孔、齿轮轴的轮齿啮合时，用**局部剖**：以波浪线为界，只剖那一小块。

横向剖切（剖切平面垂直于轴线）时，这些零件照常画剖面线。

## 接触面和配合面

- 两零件**接触**或**配合**（包括间隙配合）的表面只画一条线。
- **不接触**的表面即使间隙很小，也画两条线：螺栓杆和光孔、轴和透盖的孔、键顶和轮毂槽底。
- 被剖开的零件的剖面内，不能穿过别的零件的线。

## 断裂画法

长轴可以断开缩短画：断开处用波浪线（或双折线），尺寸仍标实际长度。
