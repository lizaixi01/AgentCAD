# F 题 简易数字扩频信号收发机：两种方式完成

题目分析见用户提供的《F题简易数字扩频信号收发机分析》。本目录用两种方式完成同一个设计任务，并比较两者。

- **方式 1 自由探索**（`free/`）：不限工具。写了一个全链路仿真，按题目指标验证方案。
- **方式 2 使用 AgentCAD**（`agentcad/`）：只用 AgentCAD 的 MCP 操作，把设计画成 3 张 A3 工程图纸。

两种方式用的是同一套设计（收发两端独立晶振，FFT 并行捕获，FLL→3 阶 PLL，2 阶 DLL，延迟补偿）。图纸 3 里的数字来自方式 1 的仿真。

> 附件一（1000 位伪码）没有随文档提供。仿真使用一条替身序列：映射为 ±1 后周期自相关主峰 1000，最大旁瓣 68（文档给出真码为 80）。
> 拿到真码后运行 `python free/dsss_sim.py --code 附件一.txt` 即可替换。

## 方式 1：自由探索（Python 仿真）

`free/dsss_sim.py` 模拟真实时间轴上的整条链路：

| 环节 | 模型 |
|---|---|
| 发射端 | DDS 载波 × ±1 伪码；载波相位按频率积分（变频时 θ = 2π∫fA du）；码率固定 1 Mcps，不绑定载波 |
| 信道 | 电缆 5 ns/m，AFE + ADC 流水线 150 ns，DAC 输出 60 ns，AWGN |
| 时钟 | 收发两端各自 ±30 ppm 的随机晶振误差 |
| 捕获 | 2 ms 数据，23 个频格（±5.5 kHz，500 Hz 步进）× 40000 点 FFT 循环相关（恰为一个码周期，不补零到 1024）；主峰/次峰 > 3 判决 |
| 复核 | 第 50 ms 的完整块上重选频格并插值、两次码相位之差估计码速率，给 FLL 和 DLL 预置 |
| 跟踪 | E/P/L 相关，1 ms 更新。1 阶 FLL 拉频 → 交接时带上频率和频率斜率 → 3 阶 PLL（Bn 20 Hz）；2 阶 DLL（Bn 8 Hz，不做载波辅助） |
| 输出 | B′ = 本地 ROM + 码 NCO，按标定的固定延迟超前；40 MS/s 输出量化 ±12.5 ns |

结果（`free/out/results.json`，每个场景 20 次随机开启，随机码相位、载波相位、晶振误差、开启时刻）：

| 场景 | 锁定 | 锁定时间 平均 / 最大 | 锁定后 max\|B′−B\| |
|---|---|---|---|
| 固定载波，1 m 电缆 | 20/20 | 0.132 / 0.142 s | 68 ns |
| 固定载波，2 m 电缆 | 20/20 | 0.132 / 0.145 s | 55 ns |
| 固定载波，C/N0 45 dB-Hz | 20/20 | 0.203 / 0.330 s | 76 ns |
| 变频，在 +5 kHz 峰值开启 | 20/20 | 0.138 / 0.197 s | 40 ns |
| 变频，在中心频率开启（df/dt 最大） | 20/20 | 0.135 / 0.186 s | 45 ns |
| 变频，长时跟踪 32 s（一个完整周期） | 1/1 | 0.131 s | 20 ns，频率误差 < 1 Hz |
| **题目要求** | | 基础 5 s / 发挥 2 s | ±200 ns |

图：`free/out/1_acf.png` 自相关，`2_tx_waveforms.png` A/B/C 波形，`3_c_spectrum.png` C 频谱，`4_acquisition.png` 捕获面，
`5_tracking_fixed.png` 固定载波入锁过程，`6_tracking_fm_long.png` 变频整周期跟踪，`7_trials.png` 100 次统计，`8_scope.png` 示波器视图。

调试中发现并修掉的问题，硬件实现时同样会遇到：

1. **3 阶 PLL 从零斜率状态启动会滑周。** 变频在中心频率时 df/dt = 1000 Hz/s，3 阶环要几百毫秒才积累出这个斜率，期间相差超过 π。改为 FLL 交接时把测得的频率斜率直接写进 PLL 的积分器。
2. **从 ±π 附近拉入相位，3 阶环会过冲很久。** 交接瞬间把 NCO 相位一次性对齐（A′/B′ 此时还未输出，相位跳变无害）。
3. **C 在处理块中间开启时会选错频格。** 首块只含零点几毫秒信号，频率分辨率远粗于 500 Hz，选到相邻频格后初始频差超过 FLL 的 ±500 Hz 鉴频范围，FLL 落在 1 kHz 混叠点上（100 次中出现 1 次）。改为在第 50 ms 的完整块上重新选频格并插值。
4. **码速率预估要用三角插值。** 无带限时相关峰是三角形，抛物线插值有偏，码速率误差使 B′ 在 DLL 收敛前漂到 0.17 chip。
5. **DLL 不能用载波辅助。** 变频时载波偏 5 kHz 而码率不变，按 fc/4 辅助会引入 1250 chip/s 的错误速率。

仿真未包含的：模拟滤波器的群延迟与幅频特性、ADC 量化、温漂。这些在硬件上要靠一次实测标定（τ_comp）。

## 方式 2：使用 AgentCAD

全部通过 AgentCAD MCP 的 `apply_operations` 完成（自定义 BOX / ARR 块、多段线、文字、表格、填充、尺寸、标题栏），
再用 `export_drawing` 出 PDF。DXF 和 PDF 在 `agentcad/`：

| 图纸 | 内容 |
|---|---|
| F-01 `sheet1_system` | 系统总体框图：发射端（TCXO、DDS、码 NCO+ROM、BPSK、三路输出）、电缆、接收端（AFE/ADC、I/Q 下变频、相关器、环路、FFT 捕获、A′/B′ 输出） |
| F-02 `sheet2_tracking` | 接收端跟踪环路详图（E/P/L、三种鉴别器、FLL/PLL/DLL 滤波器、两路 NCO、延迟补偿、锁定指示）+ 算法参数表 + B′ 误差预算 |
| F-03 `sheet3_timing` | 捕获与锁定时序甘特图（尺寸按 1.6 mm/ms 换算出 131 ms）、锁定后 B/B′ 20 个码片、码片边沿放大（尺寸按 10 ns/mm 标出 ±200 ns 容许窗与 76 ns 最坏误差）、仿真结果表 |

AgentCAD 在这次任务里的表现：

- **好用的**：一批近 100 个操作一次提交、失败不落盘；块 + 属性让框图重复元素很省事；每次提交都自带独立校验。
  校验抓到了一个真实错误：时序图尺寸手写了 "131 ms" 但几何长度是 209.6 mm（`DIMENSION_TEXT_MISMATCH`）。
  改成 `length_factor` 后尺寸值由几何推出，图和数字不会再不一致。另一次它抓到了表格残留的重复线。
- **碰到的问题**（可作为 AgentCAD 的改进项）：
  1. 2D 图纸不能导出 PNG（`png` 只对 3D 零件），检查图面只能出 PDF 再看。
  2. PDF 出图字体（msyh）缺 `µ`、`−`（U+2212）、组合字符 `f̂`，显示为方框；`add_text` 里的 `^` 被当作控制符吃掉。
     这些都是出图后人眼才发现的，校验不报。
  3. `add_table` 只给单元格文字打 tag，网格线没有 tag，按 tag 删除表格会留下旧网格。
  4. 没有电子元件符号库（电阻、电容、运放、ADC），模拟前端原理图画不了，所以图纸停留在框图层面。
  5. MCP 的工作区根是主 checkout 的 `playground/`，不是当前 worktree；文件要手动复制回来。

## 两种方式比较

| | 方式 1 自由探索 | 方式 2 AgentCAD |
|---|---|---|
| 回答的问题 | 方案能否满足指标（锁定时间、±200 ns、变频跟踪） | 方案长什么样、怎么交给别人做（框图、参数、时序） |
| 产出 | 可运行的仿真 + 8 张图 + 100 次统计 | 3 张带标题栏的 A3 图纸（DXF 可在 AutoCAD 里继续改） |
| 发现设计缺陷 | 能，调试中找出 5 个会让系统失锁或超差的问题 | 不能，图纸只表达设计，不验证设计 |
| 校验 | 靠自己写断言和统计 | 每步自动校验几何与尺寸一致性，但不检查出图后的字形 |
| 适合放进报告的部分 | 第 5、6、7 张图和结果表 | 三张图纸直接作为报告的方案图 |

结论：这道题的核心难度在接收端算法，必须靠方式 1 的仿真来验证；AgentCAD 适合把验证过的方案整理成规范图纸，两者是前后两步，不能互相替代。
