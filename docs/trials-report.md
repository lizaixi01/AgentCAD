# 经典任务实测报告

日期：2026-10-27。目的：用最常见的二维绘图任务和真实图纸检验 Runtime 的实际效果，不只看自动化测试。

结论先说：

- 7 个经典任务，外部 Agent（Codex CLI）全部只通过 MCP 完成，自校验全部 `passed`。
- 但**用 AutoCAD 出图目视复核后，7 张里有 5 张有肉眼可见的问题**，而当时的验证器一个都没报。其中 4 类是 Runtime 自身的缺陷。
- 修复 Runtime、给验证器补上对应检查后，把有问题的 4 个任务原样重跑：Agent 根据新警告自行修正，4 张图目视全部正常。
- 96 张 AutoCAD 自带的真实样例图纸（7.4 万个实体）全部能导入；78 张做了编辑，AutoCAD 审核**没有因我们的编辑增加任何错误**。验证器在真实图纸上的误报大幅下降，但仍有明确的局限（见文末）。

所有原始记录都在 [examples/trials/](../examples/trials/)：任务描述 `tasks/`，Codex 事件流 `runs/`（第 1 轮在 `round1/runs/`），Agent 产出的 DXF `ws/`、`round1/ws/`，AutoCAD 渲染图 `png/`、`round1/png/`，真实图纸统计 `real_dwg_survey.json`。

## 方法

- **外部 Agent**：Codex CLI 0.163，`-s read-only` 沙箱（不能用 shell 写文件），只能调用 AgentCAD MCP 工具。任务用中文自然语言描述，像普通工程师那样提要求，不告诉它用哪些操作。每个任务一个全新工作区。脚本：[run_trials.py](../examples/trials/run_trials.py)。
- **独立复核**：不采信 Agent 的自报。用 AutoCAD 2027 自己的打印功能（accoreconsole `-PLOT` 到 PNG）出图，人工逐张检查（[render_png.py](../examples/trials/render_png.py)）。之前用 LibreOffice 渲染，它不显示 MTEXT，所以所有标注数字都看不到，这也是之前没发现这些问题的原因。
- **真实图纸**：AutoCAD 2027 安装目录 `Sample\` 下全部 96 张 DWG（机械、建筑、土木、电气、动态块等）。逐张导入、读取、校验、加一条文字、再交给 AutoCAD 审核（[real_dwg_survey.py](../examples/trials/real_dwg_survey.py)）。这些样例图版权属于 Autodesk，不进仓库。

## 任务与结果

| 任务 | 内容 | 第 1 轮 | 目视复核发现的问题 | 第 2 轮 |
|---|---|---|---|---|
| T1 法兰盘 | Ø150/Ø60，6×Ø12 均布于 PCD Ø110，中心线，标注 | 14 次调用，passed | 标注显示为 "ØØ150""ØØ60""ØØ110" | 11 次调用，Agent 按警告改正，目视正常 |
| T2 长圆孔板 | 160×100、R8 圆角、两个 30×10 腰形孔、Ø20 孔，7 个标注 | 10 次，passed | 圆角标注显示为 "4X RR8" | 13 次，改正，目视正常 |
| T3 阶梯轴 | Ø30/Ø40/Ø30 三段、C2 倒角、轴线、分段与总长标注 | 8 次，passed | 尺寸全对；但台阶处和倒角处横跨直径的可见轮廓线没画（制图规范问题） | 未重跑 |
| T4 A3 图框 | 420×297、内框边距、标题栏、明细表（中文） | 9 次，passed | **所有中文显示为 "???"**；标题栏字段名与填写值重叠 | 9 次，中文和标题栏正常 |
| T5 建筑平面 | 6000×4000 房间、240 双线墙、门洞、四线窗、轴线标注 | 7 次，passed | **箭头完全看不见，轴线点画线看起来是实线**（注释尺寸没有随图纸比例放大） | 10 次，Agent 自己选了 `annotation_scale=50`，目视正常 |
| T6 修改别人的法兰图 | 无标签的旧图，6 孔改 8 孔、PCD 改 Ø115、更新标注 | 14 次（1 次 `modify` 不支持标注，改用重建），passed | 无问题 | — |
| T7 真实 DWG | 导入 AutoCAD 样例、概述、找标注、加注释、导出 DWG 并读回 | 18 次，passed | 这张图的模型空间几乎为空（内容在布局/外部参照里），Agent 如实报告"0 个标注" | — |

所有运行都是 0 次 shell 命令。每个任务 Codex 侧输入 33–62 万 token（其中约 88% 命中缓存），输出 1.7–4.7 千 token，耗时 84–143 秒。Runtime 侧不调用模型。

### 问题归因

| 问题 | 归因 | 处理 |
|---|---|---|
| "ØØ"、"RR" | Agent 写了 `Ø<>`、`R<>`，但 `<>` 本身已带前缀。**我们自己的规格编译器也犯了同样的错**（演示图 A、C 一直显示 "4X ØØ8"） | 规格编译器改为 `4X <>`；验证器新增 `DIMENSION_DOUBLE_PREFIX` 警告 |
| 中文 "???" | Runtime 的文字样式用 SHX 字体却没设大字体 | 新图默认 `gbenor.shx` + `gbcbig.shx`（国标工程字体，随 AutoCAD 安装）；验证器新增 `TEXT_GLYPHS_MISSING` |
| 标题栏重叠 | Runtime 的标题栏块布局错误 | 字段名改为小字放在格子上部、值在下部 |
| 建筑图箭头不可见 | Runtime 没有"出图比例"概念，标注尺寸固定按 1:1 | 新增 `create_drawing(annotation_scale=N)` 和操作 `set_annotation_scale`（DIMSCALE、LTSCALE，并重新生成已有标注）；验证器新增 `ANNOTATION_TOO_SMALL` |
| 规格图的竖向标注画在零件内部、压住孔中心线 | Runtime 规格编译器的偏移方向写反（目视复核时在演示图 C 上发现） | 改到零件左侧 |
| 轴的可见轮廓线缺失 | Agent 的制图知识问题；验证器只查几何和标注，查不了制图规范 | 未处理，列为局限 |

第 2 轮重跑时没有告诉 Agent 第 1 轮哪里错了，它只看到新的验证警告。T1/T2 的报告里分别写了"消除了重复 Ø 警告""已修正半径标注重复 R"。

## 真实图纸（96 张 AutoCAD 样例）

| 项目 | 结果 |
|---|---|
| 导入（DWG→DXF） | 96/96 成功，中位 3.2 秒，最长 13 秒 |
| 模型空间实体 | 共 74,285 个，最多一张 12,993 个；10 张模型空间为空（内容在图纸空间布局里） |
| 单位 | in 54 张、mm 24、ft 11，7 张未声明单位（如实报 `UNITS_UNDEFINED`） |
| 编辑（加一条文字） | 78/78 成功 |
| 编辑后 AutoCAD AUDIT | 71/78 为 0 错误。另外 7 张都是动态块样例：**AutoCAD 自己把原 DWG 转成 DXF 后审核就有同样数量的错误**（2–32 个），只经过 ezdxf 读写一次也是同样数量，所以不是我们引入的 |
| 校验耗时 | 最长 5.4 秒（1.3 万实体） |

验证器在真实图纸上的表现（修正前 → 修正后）：

| 报告 | 修正前 | 修正后 | 说明 |
|---|---|---|---|
| 标注文字与实测不符（error） | 51 | 3 | 原来把 `10R @ 7.09"`、`9T @ 11-1/4"` 这类楼梯说明当成数值比较。现在能解析英制分数和英尺-英寸，多数字或带文字的说明降为 warning。剩下 3 个是真的被改过数字的标注（如写 2700、实测 2799.15） |
| 标注未附着在几何上（warning） | 662 | 270 | 原来只认顶点，不认"落在墙线中间某点"和块内几何。现在接受与测量方向相交的边、块参照内的几何、旧式 POLYLINE 等。剩下的锚点离任何几何（加密采样后）中位 26 英寸，确实没有附着 |
| 重复实体（error） | 1196 | 1196 | 抽查为真实重复（同一位置叠放的相同块、相同直线），AutoCAD 的 OVERKILL 就是清理这类问题的 |
| 零长度等退化几何（error） | 44 | 44 | 真实存在 |
| 注释过小（warning） | — | 0 | 第一版用整图范围判断，误报 11 张（真实图纸常在一个模型空间里放多个比例的视图，且用逐个标注的 DSTYLE 覆盖比例）。改为比较每个标注自身长度与其箭头大小后，真实图纸 0 误报，建筑任务 T5 仍能检出 |

## 还没解决的问题

1. **只处理模型空间**。图纸空间布局、视口、外部参照的内容看不到（10 张样例模型空间为空；T7 也因此几乎没有内容可操作）。
2. **动态块数据会丢**。ezdxf 保存时丢弃 `ACDB_BLOCKREPRESENTATION_DATA`（导入动态块图纸时有提示），AutoCAD 审核数不变，但动态块的参数化行为可能失效。
3. **`modify` 不支持标注实体**。Agent 两次撞到这个错误，都靠删除重建绕过。
4. **版面质量不检查**。标注互相重叠（T1 第 2 轮的 Ø60 与 Ø110 在同一对角线上）、文字压线等，验证器看不出。
5. **制图规范不检查**。例如轴类零件的台阶和倒角轮廓线（T3）、剖面线、视图投影关系。
6. **Agent 成本**。每个简单任务约 35–60 万输入 token（大部分是缓存），主要来自操作目录和工具结果。

这些已加入 [limitations-roadmap.md](limitations-roadmap.md)。
