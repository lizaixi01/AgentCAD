# 功能覆盖清单

分类标准：**① 已实现且测试通过** = 有自动化测试，会从磁盘重读几何并断言结果，且至少断言了一个失败错误码；**② 已实现但测试不完整**；**③ 仅有接口或占位**；**④ 尚未实现**。
声明支持的数量不等于覆盖率：本表按"能力"列出，操作级的测试映射见 [op_test_matrix.md](op_test_matrix.md)（40/40 个操作被测试调用）。

## ① 已实现且测试通过

| 领域 | 能力 |
|---|---|
| 图纸管理 | 创建（显式单位 mm/cm/m/in/ft，blank/mechanical 模板，R2000–R2018）、读取摘要（单位、范围、图层计数、类型计数、块、标签、元数据、完整性状态）、实体查询（过滤、分页、窗口）、保存（原子写入、真实范围）、导出 DXF 各版本 / R12 / SVG / JSON |
| 基础对象 | 直线、多段线（含 bulge）、矩形（圆角/旋转/中心定位）、圆、圆弧（圆心式/三点式，角度归一化）、椭圆、样条（拟合点）、点、单行文字（对齐）、多行文字 |
| 几何编辑 | move、copy（多次）、rotate、scale、mirror（WCS 归一化、文字保持可读）、stretch（交叉窗口，标注重新测量）、offset（线/圆/弧/直边多段线）、trim（线/弧/圆）、extend（线）、fillet（两线，含 R0）、chamfer（两线）、矩形阵列、环形阵列、删除（大批量需确认）、属性修改、几何字段修改、explode |
| 图层 | 创建（颜色/线型/线宽，可幂等）、修改（开关/冻结/锁定/重命名并迁移实体）、删除（非空时保护，0 层保护） |
| 图块 | 定义/重定义（由绘图操作组成）、属性定义、插入（缩放/旋转/属性值）、修改属性 |
| 标注 | 线性（水平/垂直/对齐/旋转）、半径、直径、角度（三点）、引线+注释、简单表格（线+文字）、标题栏（带属性的块） |
| 单位 | 带单位字符串显式换算；未知单位、图纸无单位、规格缺单位时报错 |
| 约束 | 检查 15 类；顺序直接强制 12 类，强制后全部复检，冲突时不保存 |
| 独立验证 | 轮廓尺寸、孔位/孔径、孔数（按直径）、标注实测值（可按 tag 指定）、实体计数、文字、边界、重复、退化、标注文字矛盾、标注未附着、标注过期、开口轮廓、单位未定义、未定义块、文件可读性；未知需求字段给出警告 |
| 规格驱动 | 板件规格 → 带标签的操作计划 + 需求；规格冲突检测（孔破边、孔重叠、圆角过大）；规格修订就地协调（handle 保持不变、幂等、保留无关对象） |
| 文档驱动 | PDF/TXT/MD 读取；中英文规则提取尺寸、单位、孔、圆角、厚度、材料；页/行/章节溯源；矛盾、缺失、歧义检测；调用方覆盖值显式标记；Agent 引文核验；文档→新图或修订已有图；逐项核对报告 |
| 事务与恢复 | 预校验、原子批次、失败不改文件、严格模式、检查点、回滚（可再回滚）、journal、diff（对比检查点或另一文件）、崩溃恢复（精确提交副本优先）、外部修改检测、写锁 |
| 接口 | CLI（JSON 输出 + 退出码）、MCP stdio（18 个工具，官方 SDK 客户端测试 + Codex 实测）、HTTP、Python API |
| 安全 | 工作区沙箱、保留目录、扩展名白名单、覆盖保护、只读、操作白名单、预算、无 shell/eval 面 |

## ② 已实现但测试不完整

| 能力 | 缺口 |
|---|---|
| 椭圆弧（start/end 参数） | 只测了整椭圆与轴交换 |
| 样条 | 只断言了拟合点数量，没有断言曲线形状 |
| mirror 作用于 DIMENSION / INSERT / ELLIPSE | 代码路径存在（INSERT 只反射插入点），只测了 ARC、多段线、TEXT |
| offset 开口多段线 | 只测了闭合矩形的内外偏移 |
| trim 以多段线作为切割边 | 代码支持（展开成线/弧），没有专门测试 |
| 文档提取的措辞覆盖 | 只有规则覆盖的说法能被识别（见 `docspec.PATTERNS`）；其它措辞需要走 Agent 引文路线 |
| HTTP 接口 | 只有 3 个工具的冒烟测试（逻辑与 MCP/CLI 相同） |
| `entity_count` / `within_bounds` 需求 | 在演示和 spec 中被使用，没有单独的失败用例 |

## ③ 仅有接口或占位

| 能力 | 说明 |
|---|---|
| `ELLIPSE`、`SPLINE`、`HATCH`、`LEADER` 的 `modify` | `modify` 对这些类型会明确返回 `UNSUPPORTED_ENTITY`，不会静默忽略 |
| 角度标注（两线式 dimtype 2） | 验证器能测量，但没有创建操作（创建只支持三点式） |

## ④ 尚未实现

- 原生 DWG 读写（见 [limitations-roadmap.md](limitations-roadmap.md)）
- 联立约束求解器（目前只有顺序直接强制）
- 填充（HATCH）创建、多重引线（MLEADER）、AutoCAD TABLE 实体、坐标标注、公差标注（形位公差）
- 带圆弧段的多段线偏移；圆弧/多段线作为 extend 或 fillet 的目标
- 布局 / 图纸空间 / 视口；打印到 PDF
- UCS 局部坐标系管理（目前统一使用 WCS，镜像时会把 OCS 归一化）
- 除板件以外的零件族规格（例如法兰、支架）
- PDF OCR（扫描件会返回 `PDF_NO_TEXT`）
- 3D、参数化特征树、装配
